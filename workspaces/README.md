These are the outputs from the pipeline.

- `existential/` stores runtime data and artifacts for the existential profile.
- `operational/` stores runtime data and artifacts for the operational profile.
- `alignment/` stores cross-profile artifacts, including `artifacts/alignment_spec.md`.
- `skills/` is the skill store (generated skills under `skills/<profile>/`, imports under purpose categories).

Runtime state (improvement pass, experience records, living SOUL) is not here; it lives under CA home. See `docs/Workspaces-and-Generated-Artifacts.md`.
