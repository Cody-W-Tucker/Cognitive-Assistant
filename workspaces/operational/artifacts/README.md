# Artifacts

This directory contains the main generated outputs of the operational workflow.

- `human_profile.md`: human-readable operational profile for review
- `tool_specs/`: generated single-tool agent system prompt specs
- `profile_candidate_<provider>.md`: per-provider drafts `build-prompts` merges into `human_profile.md`

Generated skills live in `workspaces/skills/operational/`, not here.
